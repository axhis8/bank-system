# bank-system
## About this Project

This is my first Java project. It feels really draining but rewarding accomplishing it & I'm more than excited to continue!

This project is a personal milestone to understand Object Oriented Programming in Java. I focused heavily on keeping the code clean and modular – separating the CLI, business logic and data into their own classes intentionally.

## Features

- Register & Login with Account Number and PIN
- Show Balance
- Deposit & Withdraw Money
- Transfer Money to other Accounts
- Change PIN (or generate a random one)
- Auto-generated unique Account Numbers and PINs
- Input validation and error handling throughout

## How to Use

- Compile and run `Main.java` via terminal or your IDE
- Register a new account with `r` or login with your Account Number and PIN
- Select an option (1–6) from the menu to interact with your account
- Use `e` to exit or cancel at any input prompt

## Built With

- Java
- Java Collections (ArrayList)
- Java Scanner for CLI input
